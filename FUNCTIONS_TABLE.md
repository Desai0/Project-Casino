# Таблица реализации функций проекта "Виртуальное казино"

## Модуль базы данных (database/db.js)

| Ответственный | Название метода | Описание метода | Использованные переменные | Назначение переменных |
|--------------|----------------|-----------------|---------------------------|----------------------|
| Система | `constructor()` | Конструктор класса CasinoDatabase. Инициализирует путь к базе данных | `this.dbPath` | Путь к файлу базы данных SQLite |
| Система | `init()` | Инициализация базы данных. Создает таблицы и заполняет начальными данными | `this.db` | Объект подключения к базе данных |
| Система | `createTables()` | Создает все необходимые таблицы в базе данных (roles, permissions, players, games, game_rounds и т.д.) | `this.db` | Объект базы данных для выполнения SQL запросов |
| Система | `insertDefaultData()` | Заполняет базу данных начальными данными: роли, права, категории игр, игры, тестовые пользователи | `roles`, `categories`, `games`, `testUsers` | Данные для инициализации БД |
| Система | `getUser(nickname, password)` | Получает пользователя по никнейму и проверяет пароль. Возвращает объект пользователя с ролью и правами | `nickname`, `password`, `user`, `role`, `permissions` | Данные для аутентификации пользователя |
| Система | `createUser(nickname, password)` | Создает нового пользователя в базе данных. Хеширует пароль и устанавливает начальный баланс 10000 | `nickname`, `password`, `hashedPass`, `result` | Данные для регистрации нового пользователя |
| Система | `getUserById(userId)` | Получает пользователя по его ID вместе с ролью и правами | `userId`, `user`, `role`, `permissions` | ID пользователя для поиска |
| Система | `updateBalance(userId, newBalance)` | Обновляет баланс пользователя в базе данных | `userId`, `newBalance` | ID пользователя и новый баланс |
| Система | `addGameRound(userId, gameId, amount)` | Добавляет запись об игровом раунде и обновляет баланс пользователя | `userId`, `gameId`, `amount`, `user`, `newBalance` | Данные игрового раунда |
| Система | `getUserStats(userId)` | Получает статистику пользователя: общее количество игр, суммарный результат, средний результат за игру | `userId`, `stats` | ID пользователя для расчета статистики |
| Система | `getBalanceHistory(userId, limit)` | Получает историю изменения баланса пользователя с расчетом баланса на каждый момент времени | `userId`, `limit`, `rounds`, `history` | ID пользователя и лимит записей |
| Система | `getTransactionHistory(userId, limit)` | Получает историю транзакций (пополнений и выводов) пользователя | `userId`, `limit`, `transactions` | ID пользователя и лимит записей |
| Система | `getAllUsers()` | Получает список всех пользователей с их ролями | `users` | Массив всех пользователей |
| Система | `updateUserRole(userId, roleId)` | Обновляет роль пользователя | `userId`, `roleId` | ID пользователя и новая роль |
| Система | `getGameIdByName(gameName)` | Получает ID игры по её названию | `gameName`, `game` | Название игры для поиска |

## Примечания

- Все функции используют современный JavaScript (ES6+)
- Асинхронные функции используют `async/await` для работы с базой данных
- Статистика игр сохраняется в `localStorage` для сохранения между сессиями
- IPC (Inter-Process Communication) используется для связи между главным процессом (Node.js) и рендер-процессом (браузер)
- Все функции имеют обработку ошибок через `try/catch`
