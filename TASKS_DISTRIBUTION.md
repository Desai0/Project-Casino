### Задача 1: Таблица для платежей Stripe
**Файлы:** `DB/db/schema.sql`, `DB/db/payments.js`

**Что сделать:**
- Создать таблицу `stripe_payments`:
  ```sql
  CREATE TABLE IF NOT EXISTS stripe_payments (
    payment_id INTEGER PRIMARY KEY,
    profile_id INTEGER NOT NULL REFERENCES players(profile_id),
    stripe_payment_intent_id TEXT UNIQUE,
    amount INTEGER NOT NULL CHECK (amount > 0),
    status TEXT NOT NULL CHECK (status IN ('pending', 'succeeded', 'failed', 'canceled')),
    created_at TEXT NOT NULL,
    completed_at TEXT
  );
  ```
- Создать индексы для быстрого поиска по `profile_id` и `stripe_payment_intent_id`
- Создать DAO модуль `DB/db/payments.js` с функциями:
  - `createPayment({ profileId, stripePaymentIntentId, amount, status })`
  - `updatePaymentStatus({ paymentId, status, completedAt })`
  - `getPaymentsByProfile({ profileId, limit, offset })`
  - `getPaymentByStripeId(stripePaymentIntentId)`

**Критерии готовности:**
- ✅ Таблица создается при инициализации БД
- ✅ Все функции протестированы
- ✅ Индексы созданы
