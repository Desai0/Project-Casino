```bash

```

## ⚠️ Устранение неполадок

### Ошибка при установке better-sqlite3

**Windows:**
```bash
npm install --global windows-build-tools
```

**macOS:**
```bash
xcode-select --install
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt-get install build-essential python3
```

### Приложение не запускается

1. Убедитесь, что Node.js версии 16+ установлен
2. Удалите `node_modules` и `package-lock.json`
3. Выполните `npm install` заново

### База данных не создается

Проверьте права на запись в директории приложения.
