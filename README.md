## 🗄️ База данных

Приложение использует SQLite базу данных (`casino.db`), которая создается автоматически при первом запуске.

### Структура БД:

- **players** - профили игроков
- **roles** - роли пользователей (Игрок, Стример, Админ)
- **permissions** - права доступа для ролей
- **game_categories** - категории игр
- **games** - доступные игры
- **game_rounds** - история игровых раундов
