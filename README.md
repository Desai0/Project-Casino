# Casino Electron Client

Шаблон проекта для команды разработки интерфейса на Electron + Vanilla JS.

## Структура проекта

```text
/
├── package.json       # Зависимости и скрипты запуска
├── src/
│   ├── main.js        # Главный процесс Electron (Backend-like)
│   ├── preload.js     # Мост безопасности между UI и системой
│   ├── index.html     # Основной HTML файл
│   ├── renderer.js    # Точка входа для JS интерфейса
│   ├── assets/        # Статика
│   │   ├── css/       # Стили
│   │   └── img/       # Картинки
│   └── js/
│       ├── api/       # Взаимодействие с Java сервером
│       ├── engine/    # (Будущее) Связь с C++ DLL
│       └── ui/        # Логика интерфейса (auth, games, dashboard)
```

## Установка и Запуск

1. **Войти в скачанный проект**:
   ```bash
   cd папка
   ```

2. **Установка зависимостей**:
   ```bash
   npm install
   ```
   *Это установит Electron и необходимые библиотеки.*

2. **Запуск в режиме разработки**:
   ```bash
   npm start
   ```
   *Откроется окно приложения.*

## Как работать

- **Верстка**: Редактируйте `src/index.html` и `src/assets/css/styles.css`.
- **Логика UI**: Добавляйте скрипты в `src/js/ui/` и подключайте их в `renderer.js`.
- **Логика C++**: Будет подключаться в `src/main.js` через `koffi`.
